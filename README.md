# Market Metrics API

A modular, lightweight Python REST API built with FastAPI and Pydantic for analyzing time-series price data, calculating moving averages, and estimating asset return volatility.

## Features
- **Data Validation**: Strict payload validation using Pydantic schemas.
- **Analytics Engine**: Pure Python statistical computations for price mean, standard deviation, total return, and moving averages.
- **RESTful Endpoints**: Clean API interface serving structured JSON responses.
- **Automated Tests**: Unit testing suite implemented with `pytest`.
